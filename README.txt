DONUT BED CLIENT - Fabric 1.21.4

HOW TO GET THE .JAR (no programming, ~5 minutes, free):
1. Make a free account at github.com and click New repository (name it anything, Public or Private).
2. Click "uploading an existing file", and drag EVERYTHING from this extracted folder in
   (including the hidden ".github" folder). Click Commit changes.
3. Click the "Actions" tab. A build called "Build mod" runs (about 3-4 minutes).
4. Click the finished run, scroll to "Artifacts", download "donut-bed-client-jar", unzip it.
5. Put donut-bed-client-1.0.0.jar in .minecraft/mods together with Fabric API (1.21.4)
   and use the Fabric Loader for 1.21.4.

USE: Press RIGHT SHIFT (change under Options > Controls > Key Binds), set options, turn Master ON,
close the menu, hold a bed in your main hand. Settings: .minecraft/config/donut-bed-client.json
